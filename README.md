# ClimbMetrics — спортивный дневник в telegram

[![Python Version](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/) 
[![Status](https://img.shields.io/badge/status-in%5Fdevelopment-orange.svg)]()

Telegram‑бот для ведения тренировочного дневника скалолаза: запись тренировок, планирование, анализ прогресса и экспорт данных. Итоговый проект по курсу Python‑разработки МФТИ.

<video controls src="video.mp4" title="Title"></video>

## Функционал

Бот представляет собой интерфейс к работе с тренировочными дневниками. Каждый такой дневник — набор тренировок спортсмена за тренировочный цикл (сгруппированные спортсменом тренировки). Доступны функции:

1. Создание тренировочного дневника — функция разделения тренировочных циклов:
	- название;
	- даты (выставляются автоматически в соответствии с датами наиболее давней и новой тренировки);
	- комментарий к дневнику (опционально).
2. Запись тренировок:
	- дата, *время, длительность*;
	- тип (трудность, болдер, ОФП, СФП, *в т.ч. фингер*);
	- *для выездов на скалы: специальные метки о районе и секторе*;
	- список трасс / упражнений;
	- комментарий к тренировке.
3. Экспорт данных:
	- выгрузка в читаемый дневник формата txt.
4. Анализ данных:
	- визуализация регулярности тренировок с цветовым разделением по типу нагрузки;
	- статистика по сложности трасс, интенсивности нагрузок;
	- помощь в периодизации: выделение пиковых нагрузок, восстановительных тренировок;
5. Планирование:
	- составление тренировочного плана (запись будущих тренировок);
	- установка напоминаний.
### Потенциальные фичи (место для расширения проекта)

6. ИИ-анализ:
    - прогноз достижения цели (по категории/ нагрузке)
    - составление тренировочного плана
    - анализ спортивных результатов и выявление слабых мест
7. Поделиться прогрессом в тренировках (соцсети):
    - поделиться конкретной тренировкой
    - поделиться статистикой

## Технологии и архитектура

- Python 3.14.2
- aiogram
- SQLite (решение о локальной БД для ускорения разработки и упрощения в рамках курсового проекта)
- pytest

Структура проекта:

```
climbing-diary-tg-bot/  
├── app/  
│ ├── bot/ # логика бота 
│ ├── config/ # настройки и переменные окружения  
│ ├── domain/ # бизнес‑логика и модели  
│ ├── infrastructure/ # работа с БД и внешними сервисами  
│ ├── lexic/ # текстовые шаблоны 
│ └── services/ # сервисы анализа, визуализации и парсер  
├── env.example # шаблон переменных окружения  
├── main.py # точка входа  
├── README.md 
├── REPORT.md # отчёт по профилированию и оптимизации а также по покрытию тестами
└── requirements.txt # зависимости
```

## Требования и установка. Запуск программы

1. Клонировать [репозиторий](https://github.com/sakurasshhii/climbing-diary-tg-bot.git).
2. Создать виртуальное окружение и установить необходимые зависимости из файла "requirements.txt".
3. Настроить переменные окружения. Создать файл ".env" на основе примера "env.example".
4. Запустить бота: `python main.py`.
