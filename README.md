## Идея проекта

Telegram-bot для ведения тренировочного дневника скалолаза. Основная задача: записывать прошедшие тренировки, планировать следующие, выводить статистику.

## Функционал

Бот представляет собой интерфейс к работе с тренировочными дневниками. Каждый такой дневник — набор тренировок спортсмена за тренировочный цикл (сгруппированные спортсменом тренировки). Доступны функции:

1. Создание тренировочного дневника — функция разделения тренировочных циклов.
	- название
	- даты (выставляются автоматически в соответствии с датами наиболее давней и новой тренировки)
	- комментарий к дневнику (опционально)
2. Запись тренировок
	- дата, *время, длительность*
	- тип (трудность, болдер, ОФП, СФП, *в т.ч. фингер*)
	- *для выездов на скалы: специальные метки о районе и секторе*
	- список трасс / упражнений
	- комментарий к тренировке
3. Экспорт данных
	- в читаемый дневник формата txt
4. Анализ данных
	- визуализация регулярности тренировок
		- цветовое разделение по типу нагрузки
	- статистика по сложности трасс, интенсивности нагрузок
		- помощь в периодизации: выделение пиковых нагрузок, восстановительных тренировок
5. Планирование тренировки
	- составление тренировочного плана (запись будущих тренировок)
	- установка напоминаний
### Потенциальные фичи (место для расширения проекта)

6. ИИ-анализ:
    - прогноз достижения цели (по категории/ нагрузке)
    - составление тренировочного плана
    - анализ спортивных результатов и выявление слабых мест
7. Поделиться прогрессом в тренировках (соцсети):
    - поделиться конкретной тренировкой
    - поделиться статистикой
